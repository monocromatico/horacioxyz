Starbucks Corporate Latam
  • Role: Technical Lead & UX Engineer
  • Year: 2020-2025
  • Agency: Gonet - Orioninc
  • Client: Starbucks

We revamped the Starbucks Corporate site to align with modern design principles, enhancing user experience and accessibility across all devices. Following corporate US branding guidelines, we implemented a decoupled design and developed a new React/Next.js component library to ensure consistency and scalability. We implemented a Drupal backend for efficient content management, enabling non-technical staff to easily update site content. The project focused on improving site performance, SEO, and overall user engagement, resulting in a more dynamic and user-friendly online presence for Starbucks Corporate.

This project is used by Mexico, Colombia, Chile, Argentina, Uruguay. Each country has a separate web app with localized content and products.

This is deployed in AWS using Cloudfront, S3, Lambda, and Drupal as a headless CMS.
